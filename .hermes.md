# BukoNetwork (`bukonetwork.com`) Skill Routing & Folders

## Project Directories
- `apps/web/` — Frontend & video-guided physical profile quiz (`survey-react-ui`, `react-player`, `xstate`, `json-logic-js`)
- `services/exercise-studio/` — Faceless exercise motion-transfer service
- `services/podcast-editor/` — Automated 3-phone DOAC podcast video editor
- `data/MediaQueue/` — Watch folders (`raw_exercises/`, `raw_podcasts/`, `rendered_output/`, `quarantine/`)

## Automatic Skill Triggers for BukoNetwork
- When generating or fixing faceless exercise videos -> `skill_view("faceless-motion-studio")`
- When editing the physical profile quiz or pre-made lesson routing -> `skill_view("video-profile-quiz")`
- When editing 3-phone podcast videos -> `skill_view("doac-podcast-editor")`
- When checking app uptime, queues, or MIT licenses -> `skill_view("autonomous-platform-ops")`

> NOTE (Pink, 2026-10-13): the folder paths above are the playbook's TARGET structure for when
> the app is rebuilt into that layout. The current repo is a flat HTML/PWA + Supabase build
> (`index.html`, `admin_dashboard.html`, `scripts/`, `manifest.json`, `service-worker.js`).
> Neither structure was deleted or reorganized — routing rules apply regardless of layout.
